WLC setup

The controller pushes its data to this server (model-driven telemetry, gRPC dial-out). Fill in the addresses, copy the configuration and paste it in configuration mode on the Catalyst 9800. Nothing is changed on the controller from here.

1. Addresses

An IP address. The controller does not resolve a name here.
TCP, must be open from the controller to this server.
Usually the wireless management address. Empty leaves the choice to the controller.
If the controller rejects telemetry receiver protocol, use inline.

2. Subscriptions

Gives each access point its location and tags, and lets an empty access point be stored as 0.

Pick subscription ids that are not in use on the controller: show telemetry ietf subscription all.
