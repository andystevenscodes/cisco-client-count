Power BI

The counts are stored in PostgreSQL and exposed as three views. Power BI can read them through the web export (no driver, works with scheduled refresh) or straight from the database. Times come in UTC and in local time ({{ tz }}).

The data

Use ap-counts-hourly for occupancy over weeks or months; ap-counts for the detail of recent days. Relate both to access-points on wlc + ap_name, or use the location and tag columns that are already included.

Option A: web export

In Power BI Desktop: Get data → Web, paste a URL, and when asked for credentials choose Basic with user powerbi and the export token as password.

{{ base_url }}/export/ap-counts-hourly.csv?days=365
{{ base_url }}/export/ap-counts.csv?days=30
{{ base_url }}/export/access-points.csv

Parameters

days=30
the last N days (default 30, hourly 365)
from=2026-01-01
start, local time; also 2026-01-01T08:00
to=2026-02-01
end, exclusive
wlc=NAME
one controller only
.json
instead of .csv for JSON

Test from a shell

curl -u powerbi:EXPORT_TOKEN "{{ base_url }}/export/ap-counts.csv?days=1"

Option B: PostgreSQL

{% endif %}

In Power BI Desktop: Get data → PostgreSQL database.

Server
{{ db_host }}:{{ db_port }}
Database
ccc
User
powerbi (read-only, views only)
Password
POWERBI_DB_PASSWORD from .env
Tables
powerbi_ap_counts, powerbi_ap_counts_hourly, powerbi_access_points

The database port is bound to localhost by default. Set DB_BIND=0.0.0.0 in .env to reach it from another machine, and limit who can reach it with the firewall.

Example query

SELECT hour_local, location, sum(clients_avg) AS clients
  FROM powerbi_ap_counts_hourly
 WHERE hour_local >= now() - interval '7 days'
 GROUP BY hour_local, location
 ORDER BY hour_local;
